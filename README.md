# ASTARVAA

> **Indian Ideas · Timeless Stories**

A minimal, luxury "Coming Soon" hero experience for **ASTARVAA**, blending Vedic cultural heritage, earthy mineral tones, and dynamic modern micro-interactions.

---

## ✨ Features

- **Hero Artwork Integration**: Warm terracotta mountains, rising sun, and parchment canvas textures.
- **Brand Typography**: Gilded archer bow & arrow emblem with metallic foil gradients.
- **Interactive Parallax**: Dynamic 3D depth responsiveness to mouse movement and mobile tilt.
- **Ambient Golden Dust**: Subtle canvas particle system simulating sunlit dust motes.
- **Harmonic Dawn Soundscape**: Pure Web Audio API ambient drone synthesizer (432Hz harmonic resonance, muted by default).
- **Responsive Architecture**: Fully responsive across mobile, tablet, and 4K displays.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or run a local static server:

```bash
# Using Python
python3 -m http.server 3000

# Using Node.js
npx serve
```
